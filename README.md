# 급식 전광판 v6

## v6 · Flip 시간 선택 호환성 수정

- 설정에서 시간을 누르면 웹페이지 안의 시·분 버튼이 나타납니다. Flip에서 `NOT SUPPORTED`가 나올 수 있는 기본 시간 입력창(`input type="time"`)을 사용하지 않습니다.
- 0~23시와 5분 단위 버튼으로 선택하고 `−1분` / `+1분`으로 정확한 분을 조절합니다. `이 시간 선택`은 작성 중인 설정에만 반영하며, 마지막에 **저장**을 눌러야 전광판에 적용됩니다.
- 설정창도 브라우저의 기본 대화상자를 호출하지 않고 페이지 안에서 열립니다.
- **취소/닫기**는 저장하지 않은 변경을 버립니다. **기본값 복원**도 저장 전에는 취소할 수 있습니다.
- 입장 순서가 뒤바뀌거나 종료가 마지막 입장보다 빠르거나 같은 시간이라면 저장 전에 안내합니다. 여러 학년을 같은 시각에 입장시키는 설정은 가능합니다.
- 제한된 iframe에서 브라우저 저장이 차단되면 현재 화면에만 적용되며, 새로고침하면 유지되지 않는다는 안내를 보여줍니다.
- v5의 네트워크 시간 동기화와 한국 시간 계산은 그대로 유지합니다. 시간 선택 UI는 시스템 시계 값을 변경하지 않습니다.

### 기존 GitHub Pages에 반영

기존 저장소의 `index.html`, `app.js`, `style.css`를 v6 파일로 함께 교체하세요. 주소·장치 등록·서버 설정을 바꿀 필요는 없습니다. 배포가 끝나면 Flip 브라우저에서 급식 페이지를 새로고침합니다. 통합관리 iframe에서 송출 중이면 다시 송출하거나 Flip의 고정 페이지를 새로고침하세요.

기존 설정 저장 키를 유지하므로 같은 브라우저에서는 저장한 시간표를 그대로 읽습니다. 이 폴더의 수정은 로컬 작업본이며 GitHub에 자동 게시된 것은 아닙니다.

### 검증

`node tests/test_app.js`로 기본 시간 입력창/대화상자 제거, 시·분 선택, 1분 조절과 경계값, 취소, 저장, 순서 검증, 기본값 복원, 저장 차단 안내, 기존 iframe 시계 동작을 확인했습니다. 실물 Flip에서의 터치 동작은 반영 후 확인해야 합니다.

## 실행

압축을 풀고 이 폴더에서 실행합니다.

```bash
python3 -m http.server 5173
```

브라우저에서 엽니다.

```text
http://localhost:5173
```

시연 모드:

```text
http://localhost:5173?demo=1
```

## v3 변경점

- 시작 화면 없이 전광판이 바로 표시됩니다.
- 화면 오른쪽 위에 현재 시각이 항상 표시됩니다.
- 12:40 전에는 `급식시간 전입니다`가 표시됩니다.
- 13:30 이후에는 `급식시간이 아닙니다`가 표시됩니다.
- 이전 버전 service worker 캐시를 해제합니다.
- `type="module"`을 제거해서 로컬 파일/구형 브라우저에서도 더 잘 작동합니다.
- `structuredClone` 등 일부 구형 브라우저에서 멈출 수 있는 신형 문법을 제거했습니다.

## 운영 팁

소리는 브라우저 정책 때문에 자동으로 바로 켜지지 않습니다.
운영 시작 전에 화면 아래쪽의 `소리 켜기` 버튼을 한 번 눌러 주세요.

기존 버전이 계속 보이면 브라우저에서 강력 새로고침을 하거나 주소를 아래처럼 열어 주세요.

```text
http://localhost:5173?demo=1&v=3
```


## v4 변경 사항

- 1920×1080 모니터 기준으로 글씨가 잘리지 않도록 고정 캔버스형 레이아웃으로 조정했습니다.
- 제목, 현재 시각, 학년 표시, 버튼 영역의 최대 크기를 제한했습니다.
- 작은 테스트 화면에서는 자동으로 축소됩니다.

## v5 변경 사항

- 통합관리의 보안 iframe 안에서도 Service Worker 권한 오류가 시계 표시를 막지 않도록 수정했습니다.
- 화면을 먼저 그린 뒤 제한된 브라우저 기능을 확인하므로 초기 시각이 `--:--:--`에 멈추지 않습니다.
- 웹 서버의 `Date` 응답으로 10분마다 시간을 동기화하고, 실패하면 기기 시간으로 계속 동작합니다.
- 기기 시간대 설정과 관계없이 대한민국 표준시(UTC+9)로 급식 시간표를 계산합니다.
